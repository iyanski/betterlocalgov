## 6. Open questions and rules I was unsure how to apply

- **How sources were "opened".** The web-fetch tool returns a model-written summary, not raw HTML. Where I quote, the quotes come from that summary's verbatim extraction. This is why nothing is `verified` and why section 4 asks for a browser check.
- **`national_applicable` for the hazard-tools page.** The fixed notice speaks of a "national government procedure". The page is a set of links to national tools, so the notice is slightly off-topic but harmless. Consider a separate neutral scope value or notice if you want to refine it.
- **`fil` locale.** The brief says to add `ilo` "alongside `en` and `fil`", but `fil` exists only as unused starter-kit strings in `src/i18n/locales/fil.json`; the runtime loads only `public/locales/en`. I registered `fil` as disabled and `needs_review` and left its file alone.
- **Drafts are still bundled.** _Resolved in `fix/phase-4-draft-exclusion`:_ production builds now stub non-public content out of the bundle, and `scripts/check-dist-leaks.mjs` fails the build if draft text reaches `dist/`. See [Content verification](content-verification.md#non-public-content-never-ships). Unverified personal information still belongs outside the repository, because the repository is public.
- **Search index.** _Resolved in `fix/phase-4-draft-exclusion`:_ `scripts/index-content.mjs` now uses the shared policy in `scripts/lib/visibility.mjs` (including `national_applicable`) and indexes public projects.
- **`vercel.json` and `public/.htaccess` were not changed**, as the brief asks me to ask before touching deployment config. Pre-rendered pages are directory index files (`/hotlines/index.html`), which both configs already serve before falling back to `index.html`. Apache will redirect `/hotlines` to `/hotlines/`; canonical URLs have no trailing slash. See `docs/spa-deployment.md`.
- **CORS.** The weather API allows only `https://bettergattaran.org`. `www.` and `localhost` get the Open-Meteo fallback.
- **Open-Meteo terms.** The free API is for non-commercial use under CC BY 4.0, with call limits. The card credits it. Confirm the site stays within "non-commercial".
- **Weekly link check and DPWH.** DPWH pages opened fine here but `dpwh.gov.ph` is in the skip list; decide whether to keep skipping it.
- **Rule 3 wording.** I set `lastVerifiedAt` to 2026-10-12 on the new `sourced` records (the date I opened the sources) and attributed the check to the agent in the register. If you want `lastVerifiedAt` reserved for human checks, remove it from those records.
- **Not done.** Section 4c charts and SRE/COA/FDPP/PhilGEPS content, 4d CMCI, 4f facilities, and the PSA/PhilSys/4Ps/DOLE guides: all blocked by access, as listed in section 3. No chart component was written because no figures could be sourced.
